# 00 可行性結論與設計決定

日期：2026-10-02。來源：與專案擁有者的一次完整訪談（grilling）＋對四個資料來源的實測核實。
本文件是其他 session 的「憲法」：沒有新事實不要推翻這裡的決定；有新事實請在此追加一節而不是改寫歷史。

## 結論

**可行，且沒有需要發明新技術的環節。** 所有輸入（腳本、立繪、背景、BGM、音效、幹員原聲）都有機器可讀的公開來源；
語音克隆用成熟的開源零樣本模型；渲染是自寫網頁渲染器逐幀截圖。真正的工作量在：
1. 寫腳本解析器與時間軸生成；
2. 寫渲染器；
3. 在 SCRP 叢集裝好 TTS 環境並跑批次；
4. 選角（約 100 個說話者的聲線分派）與質檢回路。

主要風險不在技術，在版權與平台規則（見「風險」）。

## 設計決定（含理由）

| # | 決定 | 選擇 | 理由 / 放棄的替代 |
|---|---|---|---|
| D1 | 產物形式 | 預渲染 MP4 | 字幕與語音精確對齊、無即時運算、最快出結果。放棄可互動播放器（可日後用同一渲染器實現）。 |
| D2 | 語音語言 | 中文（zh_CN 腳本＋中文幹員原聲） | 核實：431/455 有語音幹員同時有中文與日語語音，覆蓋率相同；中文免去跨語言合成與雙腳本對齊。 |
| D3 | 克隆引擎 | 幹員：開源零樣本克隆（首選 IndexTTS-2，備選 CosyVoice 3 / GPT-SoVITS）。NPC、旁白、博士：ElevenLabs Voice Design（文字描述生成全新聲線） | ElevenLabs 條款要求克隆須得聲音主人同意，拿聲優原聲克隆違規有封號風險；Voice Design 不涉克隆。開源引擎無此限制，中文品質成熟。 |
| D4 | 運算環境 | Mac 做所有非 GPU 工作；SCRP 叢集（RTX 3090）只跑自包含批次 TTS；rsync 交換 | 使用者有 Mac 與 SCRP 帳號；把叢集端面積縮到最小以降低環境風險。 |
| D5 | 首個範圍 | 巴別塔 act33side，先 BB-ST-1「未完成的告别」（127 行）跑通，再批量其餘 22 場 | 最短場景但含全部典型元素（旁白、NPC、立繪、背景、Sticker 字卡、BGM、音效）。 |
| D6 | 博士台詞 | 配音：設計一個「巴別塔時期博士」聲線 | 使用者明確要求。巴別塔博士 467 行（10%）。 |
| D7 | 旁白 | 固定一個旁白聲線念出；Sticker 時間地點字卡只顯示不念 | 廣播劇標準做法；避免大段靜音。 |
| D8 | NPC 選角 | 分層選角表 casting.yaml：幹員→原聲克隆；行數 ≥ 30 的主要 NPC→各一個 Voice Design；其餘路人→按性別/年齡/氣質指向約 8–10 個共用聲線；未指定者落到預設聲線並在報告中列出 | 104 個說話者逐一設計成本高且路人只有幾句。身份以「說話者名＋charslot 立繪 id」為鍵（「？？？」「“阿米娅”」是假名；「萨卡兹雇佣兵」可能是不同人）。 |
| D9 | 視覺素材來源 | PRTS wiki 的機器可讀索引（Widget:Data_Image / Data_Char / Data_Link / Data_Audio）→ media.prts.wiki / torappu.prts.wiki | Aceship/Arknight-Images 已過時（巴別塔背景與新 NPC 立繪全部 404）；yuanyan3060/ArknightsGameResource 無 avg 素材。PRTS 索引對巴別塔覆蓋 48/48 背景、199/199 立繪名、18/18 BB-ST-1 音訊鍵。 |
| D10 | 渲染方式 | 自寫 HTML/Canvas 渲染器，Playwright 以虛擬時鐘逐幀截圖，ffmpeg 編碼混音 | 使用者兩次確認。可做打字機、立繪滑入、震動、淡入淡出；同一渲染器日後可直接變互動播放器。放棄 Python 靜圖方案（快但動效少）與改造 PRTS 播放器（他人壓縮 bundle、點擊推進、授權不明）。 |
| D11 | BGM / 音效 | 全部按腳本指令加入原版 BGM 與音效（intro/loop、淡入淡出、音量指令） | 使用者要求「原版＋語音」。版權識別風險已告知並接受。 |
| D12 | 語音質檢 | 每句生成後用中文 ASR（FunASR Paraformer 或 Whisper）回轉文字比對字錯率；超閾值換種子重生最多 3 次；仍失敗列入人工聽審報告。另維護專有名詞拼音表強制讀音 | 4400 句人工全聽要 5–6 小時；目標人工聽審 < 5%。 |
| D13 | 情緒控制 | 第一版不控情緒；資料結構預留 `emotion` 欄位 | 先聽 BB-ST-1 效果再決定是否用 LLM 批量標情緒。 |
| D14 | 節奏 | 每句停留 = 語音長度 + 0.5 s；腳本自帶 Delay / Blocker / Sticker 時長照用；無語音的字卡按字數停留（基準 1.0 s + 每字 0.12 s） | 專案擁有者授權由管線自行決定的預設值；可在設定檔改。 |
| D15 | 輸出規格 | 1920×1080、30 fps、H.264 + AAC；遊戲座標系 1280×720 等比放大 1.5 | 同上。 |
| D16 | 入庫原則 | 遊戲素材、原聲、生成音訊/影片一律不入 git（.gitignore 已設）；只入程式、設定、文件、選角表 | 版權＋體積。 |

## 已核實的關鍵數字

- 巴別塔 23 場、4400 行（含旁白 761、博士 467）、104 個不同說話者；行數 ≥ 30 的 NPC 約 10 人。
- 腳本指令頻次（全巴別塔）：name 3639、charslot 2987、Blocker 842、dialog 566、delay/Delay 859、PlaySound/playsound 497、Background 194、Sticker 178、Dialog 147、Subtitle/subtitle 181、CameraShake 105、stopmusic 104、PlayMusic/playMusic 82、Image/image 81、Effect 41、interlude 39、curtain 34、bgeffect 32、ImageTween 28。
- BB-ST-1：127 行；4 張背景；14 個立繪名（凯尔希、阿斯卡纶、4 個 NPC 立繪、npc_10002）；BGM 3 組 intro/loop；音效 12 個鍵。

## 風險與對策

| 風險 | 嚴重度 | 對策 |
|---|---|---|
| 版權：鷹角/悠星對同人寬容，但 BGM 最易被 bilibili 音訊指紋識別導致靜音或下架 | 中 | 投稿頁註明同人、非盈利、官方要求即刪；BGM 軌獨立可一鍵關閉重出。 |
| 中國《人工智能生成合成内容标识办法》2025-09-01 起強制，bilibili 投稿須勾選 AI 生成聲明 | 高（不勾會被下架） | 投稿清單強制項；片頭/簡介明示「語音由 AI 生成」。 |
| ElevenLabs：只用 Voice Design，不上傳任何聲優音訊 | 中 | 管線層面禁止 ElevenLabs 路徑接收 refs/ 目錄的檔案。 |
| PRTS 伺服器對連續請求重置連線（實測） | 低 | 下載器限速（≥ 1 s 間隔）、重試、本地快取；只下載當前場景需要的素材。 |
| SCRP 計算節點是否有外網未確認；學生 QoS 可能只給 1 GPU / 1 天 | 中 | S0 先偵察；模型權重在登入節點下載到 ~/large-data。 |
| 零樣本克隆品質因參考音品質而異（遊戲語音有混響/音效） | 中 | 參考音自動篩選：5–15 s、無 BGM、能量穩定；每角色備 3 段候選。 |
| 多音字與專有名詞讀錯 | 中 | 拼音表（lexicon.yaml）＋ ASR 回檢。 |
